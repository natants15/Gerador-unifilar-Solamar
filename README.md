# Gerador Unifilar Solarmar

App web que recebe um documento de vistoria ou memorial técnico e gera automaticamente o diagrama unifilar em DWG, seguindo os padrões técnicos da concessionária do projeto.

## Fluxo previsto

1. Upload do documento de vistoria / memorial técnico (PDF, DOCX ou imagem).
2. Extração dos dados elétricos: padrão de entrada, disjuntores, condutores, medição, aterramento, geração (ex.: sistema fotovoltaico, inversores, string box).
3. Seleção da concessionária e aplicação das regras e simbologia da norma correspondente.
4. Geração do diagrama unifilar em DWG/DXF, pronto para revisão no AutoCAD.
